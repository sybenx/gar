The theme was generated using [Material Theme Builder](https://material-foundation.github.io/material-theme-builder/).
To obtain the same result:
- Set `#006800` as the source color
- Make sure "Color match" is **not** ticked
- Set `#daec21` as the tertiary color
- Leave everything else (including fonts) to the default values, and export the theme

GAR: the colors are now GAR's Tide palette. They come from the same Tonal Spot scheme (Material
color utilities, 2021 color spec) with `#006A60` as the source color and no custom tertiary. The
"on container" colors of the standard light scheme use tone 10, and the error colors are the
standard ones above, unchanged.
